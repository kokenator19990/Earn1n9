## 🚀 Características

- **🚨 Alertas GO NOW**: Identificación en tiempo real de oportunidades de trading (Rate > 4.0).
- **🐶 Mascota Interactiva**: Perro guardián que ladra al hacer click.
- **📱 Optimizado para Móvil**: Diseño responsivo para operar desde el teléfono.
- **🪐 Integración Binance**: Links directos a Binance Futures en cada moneda.
- **📡 Datos en Vivo**: Conectado a la API de Binance Futures (Ticker + Premium Index).

## 🛠️ Ejecución Local (Backend Python)

Si quieres correr la versión completa con el backend en Python (para desarrollo o mayor velocidad):

1. **Instalar dependencias**:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **Ejecutar**:
   ```bash
   python -m src.main
   ```

3. **Abrir**: [http://localhost:8000](http://localhost:8000)
